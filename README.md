## 🎯 Problem
Brinjal farmers in India lose up to 30% of their crop every
season due to pest attacks. Chemical pesticides cost ₹5,000
per crop and harm health and environment.

## 💡 Solution
AgroVision is an AI powered smart farming system that:
- 🐛 Detects insects and pests using AI cameras (YOLO)
- 💧 Monitors soil moisture using IoT sensors
- 🤖 Makes organic farming decisions using AI Agent
- 📱 Sends instant alerts to farmer's phone via Telegram
- 🌿 100% organic — zero chemicals needed

## 🛠️ Technologies
- Python 3.14
- YOLOv8 (Ultralytics)
- PyTorch
- LangChain + Claude API
- Firebase
- Raspberry Pi 4
- FastAPI
- React.js
- Telegram Bot API
